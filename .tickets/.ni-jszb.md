# Add visual bell and notification sound to pi agent notify extension

Enhance the existing notify.ts pi agent extension (~/.pi/agent/extensions/notify.ts) with two additions:

## Visual bell in Ghostty tab

The current extension sends an OSC 777 desktop notification on agent_end. Add a BEL character (\x07) or Ghostty-specific escape sequence so the tab itself gets a visual indicator (dot/badge) when the agent finishes. This makes it easy to spot which tab needs attention when running multiple worktrees with agents.

Currently notify.ts only does:

```
process.stdout.write(\`\x1b]777;notify;${title};${body}\x07\`);
```

Add a standalone BEL (\x07) write for the tab bell, and check if Ghostty supports tab title changes via OSC sequences (e.g. OSC 0 or OSC 2 to set tab title to include a status indicator).

## Notification sound via peonping

Integrate peonping (https://www.peonping.com/) sound notifications on agent_end. peonping plays game character voice lines (e.g. Warcraft peon 'Work, work.' or 'Something need doing?') when an agent finishes or needs input.

Install: `brew install PeonPing/tap/peon-ping`

Options to evaluate:

1. Run peon-ping as a standalone process that hooks into pi — check if it has native pi/generic terminal agent support
2. Call peon-ping's CLI directly from notify.ts on agent_end (e.g. spawn `peon play complete`)
3. Use peon-ping's MCP server if that fits better with pi's architecture

## Acceptance criteria

- [ ] Ghostty tab shows visual indicator (bell/dot) when agent finishes and tab is not focused
- [ ] A sound plays on agent_end via peonping
- [ ] Both features work when running multiple pi agents in separate Ghostty tabs/worktrees
- [ ] Sound volume is configurable or respects peonping config
- [ ] Extension degrades gracefully if peonping is not installed (visual bell still works, no sound error)
