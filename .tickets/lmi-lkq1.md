# Add lat-md authoring skill for pi agent

Create a global pi skill that teaches agents how to write and maintain lat.md knowledge graph files.

The skill content already exists in lat.md's official template at templates/skill/SKILL.md in the lat.md GitHub repo. It covers section structure, wiki link syntax, code refs, test specs, and validation rules.

This is a global skill — available in all repos, not per-project. The per-project extension (tools + hooks) is generated by running `lat init --agent pi` in each repo.

Files:

- home/configs/pi-coding-agent/skills/lat-md/SKILL.md — new file, adapted from https://github.com/1st1/lat.md/blob/main/templates/skill/SKILL.md
- home/configs/pi-coding-agent/default.nix — auto-discovers new skill dir, no changes needed

## Acceptance Criteria

1. skills/lat-md/SKILL.md exists with proper frontmatter (name: lat-md, description)
2. Skill covers: what belongs in lat.md, section structure, wiki links, source code links, code refs, test specs, validation
3. Skill content adapted from lat.md official template (not copy-pasted blindly — adapted for pi context)
4. After staging + devenv tasks run home:apply, skill is symlinked at ~/.pi/agent/skills/lat-md/SKILL.md
5. Running pi in TUI mode shows lat-md in available skills list
