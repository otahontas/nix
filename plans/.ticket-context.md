## Verification commands

- Build/enter shell: `devenv shell`
- Check rtk available: `devenv shell -- rtk --version`
- Check extension loads: restart pi and verify no errors

## Key directories

- `devenv.nix` — devenv config, add `pkgs.rtk` to packages
- `~/.pi/agent/extensions/` — global pi extensions, where `rtk.ts` will live

## Conventions

- Extensions use `export default function (pi: ExtensionAPI)` pattern
- Extensions are plain TypeScript, loaded via jiti (no build step)
- `createBashTool` with `spawnHook` is the documented way to intercept bash commands
- Existing `guardrails.ts` shows the `tool_call` event pattern for reference
- nixpkgs#rtk is v0.30.0 (behind latest v0.35.0 but functional)
- `rtk rewrite <cmd>` exits 0 with rewritten command on stdout, exits 1 if no rewrite needed
- The `spawnHook` must be synchronous-style (execSync) since it returns a value synchronously
- `devenv.nix` already has a custom package pattern (ollama-bin) for reference
