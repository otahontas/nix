## Verification commands

- Build/apply: `devenv up` or `home-manager build --flake .#otahontas`
- Lint: pre-commit hooks in devenv.nix (deadnix, typos, etc.)
- Test: no automated tests — verify by opening fish and bash shells

## Key directories

- `home/configs/` — per-program nix modules, each in its own subdirectory
- `home/configs/fish/config.fish` — main fish interactive init + functions
- `home/configs/bash/default.nix` — bash config (currently minimal)
- `home/configs/git/` — git aliases, worktree functions (fish-only)
- `home/configs/neovim/` — todo/daily functions (fish-only)
- `home/configs/pi-coding-agent/` — pic/pir aliases (fish-only)
- `home/configs/bat/` — cat alias (fish-only)
- `home/configs/fd/` — find-and-prune function (fish-only)
- `home/configs/qpdf/` — combine-pdfs-in-folder function (fish-only)
- `home/configs/devenv/` — fish completions for devenv tasks
- `home/configs/yubikey-manager/` — yk-status function (fish-only)

## Conventions

- Each program gets its own directory under `home/configs/` with a `default.nix`
- Shell functions live in `.fish` files alongside `default.nix`
- Programs with home-manager support use `programs.<name>.enable` which auto-configures both fish and bash integrations
- Scripts/tools that don't need to cd should be `writeShellScriptBin` packages — works in any shell
- Aliases should be defined once and shared: `programs.bash.shellAliases = sharedAliases; programs.fish.shellAliases = sharedAliases;`
- Only 3 functions need to stay as shell functions (they cd): `gwnew`, `gwpr`, `gwcd`
- Fish completions can't be shared with bash — those stay fish-only
- The `__devenv_auto` PWD hook is fish-only; bash equivalent uses `PROMPT_COMMAND` or `cd` override

## Migration strategy

1. Create a shared aliases nix let-binding, apply to both shells
2. Convert non-cd functions to `writeShellScriptBin` scripts
3. Keep cd-dependent functions as shell-specific implementations (fish + bash)
4. Remove fish-only function definitions after replacing with scripts
5. Add bash equivalents for cd-dependent functions
